# 001 — SEO Improvements

## Priority 1 — Critical

### 1. Update `<title>` to include location
**File:** `landing.html`

Current:
```html
<title>Bringo — Kéz- és Lábápolás</title>
```
Proposed:
```html
<title>Bringo — Kéz- és Lábápolás | Alsóörs</title>
```

---

### 2. Add `<meta name="description">`
**File:** `landing.html`

Add inside `<head>`:
```html
<meta name="description" content="Manikűr, géllakk, műköröm és lábápolás Alsóörson. Bejelentkezés: +36-20/560-4807">
```

---

### 3. Add JSON-LD LocalBusiness schema
**File:** `landing.html`

Add inside `<head>`:
```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "NailSalon",
  "name": "Bringo",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "Endrődi Sándor u. 24.",
    "addressLocality": "Alsóörs",
    "postalCode": "8226",
    "addressCountry": "HU"
  },
  "telephone": "+36205604807",
  "url": "https://yourdomain.hu/",
  "sameAs": ["https://www.facebook.com/brigitta.meszaros.1447"]
}
</script>
```
> Replace `url` with the actual domain once known.

## Priority 2 — Moderate

### 4. Add Open Graph tags
**File:** `landing.html`

Add inside `<head>`:
```html
<meta property="og:title" content="Bringo — Kéz- és Lábápolás | Alsóörs">
<meta property="og:description" content="Manikűr, géllakk, műköröm és lábápolás Alsóörson.">
<meta property="og:type" content="website">
```

---

### 5. Add canonical URL
**File:** `landing.html`

Add inside `<head>`:
```html
<link rel="canonical" href="https://yourdomain.hu/">
```
> Replace with actual domain. Prevents duplicate content issues (www vs non-www, http vs https).

---

## Priority 3 — Nice to have

### 6. Add `robots.txt` and sitemap
Once a domain is live, add a `robots.txt` at the root:
```
User-agent: *
Allow: /
Sitemap: https://yourdomain.hu/sitemap.xml
```
And a minimal `sitemap.xml` pointing to the landing page.

### 7. Tailwind build (Core Web Vitals)
Tailwind CDN ships the full unminified build (~400 KB). A purged/compiled build would be significantly smaller. Requires introducing a build step — intentionally deferred per project architecture.
